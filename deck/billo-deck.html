It really works

AI reads. Rules decide.

The model never invents advice. It extracts what’s printed; a deterministic engine turns that into steps. Same bill, same day → same answer.

1 · Read

Gemini 3.5 Flash (vision) → JSON: payee, amount, due date, late fee, confidence, plain-English summary. Auto-fallback across models; low confidence is flagged.

2 · Decide

Rule engine: late / due ≤3 days / later / no date × can-pay × bill type (medical, subscription, fine…) → max 3 steps, call scripts, .ics reminders.

3 · Return

Today queue sorts every open step by urgency; streaks and “late fees avoided” update on every tap.

Static web app, no backend · 11 unit tests on the engine · works on phone and desktop · demo never breaks: samples fall back to known values if AI is busy.
